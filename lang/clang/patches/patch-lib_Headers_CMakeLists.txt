$NetBSD$

IRIX support (from the IRIX port of LLVM, atomchild411/llvm-project
branch iris/main):
- clang: wrapper headers for what IRIX's lack, and _WCHAR_T in C++
- clang: __IRIX_VERSION__, char * va_list, and C99 gaps in the headers
- clang: C99 integer constant macros
- The C95/C99 library IRIX 6.5.7 lacks, and wide characters in libc++
- headers: work against a stock IRIX 6.5.22 root too
- headers: socklen_t for IRIX 6.5.7 roots
- headers: <sys/select.h> provides struct timeval
- headers: <uuid.h> for IRIX's DCE UUID calls
- headers: suseconds_t
- headers: <assert.h> without an include guard
- POSIX 2008 locale objects, the C locale only
- CLOCK_MONOTONIC from times()
- O_CLOEXEC for open()
- pthread_cond_timedwait_relative_np
- getaddrinfo, getnameinfo and RFC 3493's IPv6 types
- posix_spawn
- getopt_long and getopt_long_only
- POSIX 2008 string, stdio, memory and time functions
- MAP_ANON through /dev/zero
- <err.h>: err, errx, warn, warnx and their va_list forms
- <sys/file.h>: declare flock for C++
- <endian.h>, cfmakeraw, lchmod, get_nprocs
- <sys/socket.h>: no sa_len macro; <netinet/ip.h>: self-contained
- <sys/ioctl.h>: struct winsize and TIOCGWINSZ in every mode
- struct winsize from <sys/termios.h>, decided after IRIX's
- Declare POSIX functions IRIX hides outside SGI mode
- dladdr() over the runtime linker's dladdr service
- limits.h: POSIX.1-2001 minimums, PATH_MAX and NAME_MAX
- sys/timespec.h: include sys/types.h before the guard
- netinet/tcp.h: bring in the BSD types it uses
- Wrapper <byteswap.h>: bswap_16, bswap_32, bswap_64
- Wrapper <elf.h>: Elf32_Nhdr and Elf64_Nhdr
- Wrapper <resolv.h>: define sgi while IRIX's is read
- Install <sys/bitypes.h>, not <resolv.h>
- getifaddrs and freeifaddrs, with <ifaddrs.h>
- Wrappers: <sys/queue.h>, <machine/endian.h>, SUN_LEN, I, IPPROTO_SCTP
- POSIX 2008 *_l functions: ctype, wctype and collation
- Wrapper <net/if_dl.h>: an include guard, and the BSD types it uses
