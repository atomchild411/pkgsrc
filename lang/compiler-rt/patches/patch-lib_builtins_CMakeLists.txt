$NetBSD$

IRIX support (from the IRIX port of LLVM, atomchild411/llvm-project
branch iris/main):
- The C95/C99 library IRIX 6.5.7 lacks, and wide characters in libc++
- printf: C99 length modifiers, and snprintf(NULL, 0) measures
- headers: work against a stock IRIX 6.5.22 root too
- compiler-rt: getprogname and setprogname
- compiler-rt: strsignal
- compiler-rt: setenv and unsetenv
- POSIX 2008 locale objects, the C locale only
- CLOCK_MONOTONIC from times()
- O_CLOEXEC for open()
- pthread_cond_timedwait_relative_np
- getaddrinfo, getnameinfo and RFC 3493's IPv6 types
- headers: POSIX struct msghdr by default
- compiler-rt: memmem, mkdtemp, basename, dirname
- posix_spawn
- getopt_long and getopt_long_only
- POSIX 2008 string, stdio, memory and time functions
- C99 math declarations; the functions 6.5.7 lacks
- MAP_ANON through /dev/zero
- <err.h>: err, errx, warn, warnx and their va_list forms
- sysconf: the names IRIX 6.5 lacks
- <endian.h>, cfmakeraw, lchmod, get_nprocs
- long double is a double
- POSIX 2008's *at() calls and fdopendir
- dladdr() over the runtime linker's dladdr service
- pselect() over sigprocmask and select
- Runtime shims: stack protector, daemon, strlcpy/strlcat, memrchr, _Exit, vfork, __progname
- getifaddrs and freeifaddrs, with <ifaddrs.h>
- [IRIX] Keep _exit out of the string compat object
- POSIX 2008 *_l functions: ctype, wctype and collation
